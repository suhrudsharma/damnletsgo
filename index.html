How to use DamnLetsGo

📍
Select places

Tap on the map or search to add locations.(red pointer=start)

🏫
Campus Mode

Turn ON to navigate inside the campus using walking paths.

🧭
Navigate

Press Navigate to see the shortest route and distance.

⏱️
Estimate Time

Choose walk, cycle, bike, or car to see travel time.

🗑️
Clear vs Reset

Clear removes selection. Reset removes everything.
